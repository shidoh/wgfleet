# wgfleet

A controller and per-node agents that run a small fleet of AmneziaWG exits behind
one master, with REALITY/VLESS as a second transport, DNS filtering, egress
failover and a web console.

- New here: start with the [Quickstart](docs/QUICKSTART.md), then check the
  [system requirements](docs/requirements.md).
- Running a fleet: [Operations](docs/operations.md), [Upgrading](docs/upgrade.md), and the
  [support bundle](docs/support-bundle.md) when something needs a second pair of eyes.
- Every manifest key: [Configuration reference](docs/configuration.md).

Releases ship as an archive with these pages inside; this site is the same
material, always for the latest release.
